# FreshBite – Online Food Ordering

A responsive front-end web application created for the Web Development Internship task.

## Features
- Restaurant listings with search
- Restaurant menu pages
- Add/remove items and quantity controls
- Persistent shopping cart using localStorage
- Checkout and order creation
- Order history and order tracking status
- Admin menu management (add/delete items)
- Responsive mobile-friendly design

## How to run
Open `index.html` in any modern browser. No server or installation is required.

## Technologies
HTML5, CSS3, JavaScript (ES6), LocalStorage

## Demo flow
Home → Restaurants → View Menu → Add items → Cart → Place Order → My Orders.
